# Security Policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report it privately through GitHub: on this repository, open **Security → Report a vulnerability** (a private security advisory). Do not open a public issue.

Include what you found, how to reproduce it, and which version you used. You can expect an answer within 7 days.

## Scope

Codex Resume runs locally with your own permissions. Reports are especially welcome about:

- data in Codex session files or `config.json` that leads to running a command, adding arguments, or reaching the network;
- keystrokes reaching a window or process other than the chosen Codex;
- prompts, tokens or session content ending up in the log or in notifications.
