## Privacy
All of PRIV-01 to PRIV-16 are closed, except PRIV-15, which is partly closed (Low): paths outside the profile folder can still appear inside logged error texts.

Highlights:
- The cache holds no transcript text.
- The log never contains the prompt, the reset command or the profile path.
- The prompt never appears on the typing helper's command line (it goes in on stdin).
- The reset command runs from a short-lived script, not a command line.
- The v1.0 log, which could contain tokens, is deleted on upgrade.

The docs are `docs/privacy/data-inventory.md` and `docs/privacy/data-flow.md`. **Open for the owner:** confirm the personal/household-use assumption behind "lawful basis: not applicable".
